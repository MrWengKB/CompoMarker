    设置指南
    
      
    第一次使用只需要设置一次，之后这台设备上的浏览器会记住。选下面适合你的一种方式。
    

      
    
        方式一：用同事分享的中转（最简单）
        
    如果有同事已经搭好了 Cloudflare 中转并愿意分享，你只需要向这位同事要两样东西：Cloudflare 用户名和访问口令。
    
        
      
          
    1. 点右上角「设置」。
      2. 
          
    2. 「服务商」选 我的 Cloudflare 中转（Key 存在 Worker 里）。
      3. 
          
    3. 在 https://compomarker. 和 .workers.dev/qwen-intl 中间的格子里填 Cloudflare 用户名。
      4. 
          
    4. 「访问口令」填拿到的口令。
      5. 
          
    5. 勾选「在这台设备上记住」，点「保存」。
      6. 
        
    
        
    口令请不要外传：用的是搭建者自己的额度，知道口令的人都能用。
    
      
    

      
    
        方式二：自己申请通义千问 Key
        
      
          
    1. 打开 Alibaba Cloud Model Studio（国际版），用邮箱注册账号（不需要中国手机号，一般需要绑定信用卡验证）。
      2. 
          
    2. 按提示开通 Model Studio，地域选 新加坡（Singapore）。新用户有免费额度。
      3. 
          
    3. 在「API Key」页面点「创建」，复制 sk- 开头的一串字符。
      4. 
          
    4. 回到本网页，点「设置」，「服务商」选 通义千问 · 国际版，把 Key 粘贴到「API Key」，点「保存」。
      5. 
        
    
        
    如果有中国大陆手机号，也可以在阿里云百炼（国内版）申请，服务商选「通义千问 · 国内版」。两边的 Key 不能混用。
    
      
    

      
    
        方式三：自己搭一个中转（可以分享给同事）
        
    把 Key 存在自己的 Cloudflare 里（免费），在各台设备上只需填口令；想分享给同事时，也只给口令，不用给真实 Key。
    
        
      
          
    1. 先按「方式二」申请一个通义千问国际版 Key。
      2. 
          
    2. 登录 Cloudflare（免费账号即可）→ Workers & Pages → 创建 → 选「Hello World」，名字填 compomarker → 部署。
      3. 
          
    3. 点「编辑代码」，把 worker/relay.js 的内容整个粘贴进去 → 部署。
      4. 
          
    4. 进入该 Worker 的「设置 → 变量和机密」，添加两个机密（Secret）：ACCESS_CODE（自己定的口令）和 QWEN_INTL_KEY（通义千问 Key）。
      5. 
          
    5. 自己按「方式一」设置。如果想分享给同事，把 Cloudflare 用户名（Worker 地址里 compomarker. 和 .workers.dev 之间那段）和口令告诉对方即可，用量会算在你的额度里。
      6. 
        
    
      
    

      
    
        常见问题
        
    
          
    提示「访问口令不正确」
    
          
    口令填错了，注意大小写和多余的空格。
    
          
    提示「此中转只允许指定网页调用」
    
          
    请从 https://mrwengkb.github.io/CompoMarker/ 打开本网页，不要用下载到本机的文件。
    
          
    提示「无法连接到模型接口」
    
          
    检查网络，以及中转地址里的用户名是否正确。
    
          
    提示「模型不存在或已下线」
    
          
    在「设置 → 高级设置」里点「恢复该服务商的默认模型和地址」后保存。
    
          
    作文和 Key 会被保存到哪里？
    
          
    Key 只存在你自己这台设备的浏览器里；作文内容直接发给模型服务商批改，历史记录也只存在本机。
    
          
    换了电脑或浏览器怎么办？
    
          
    每个浏览器需要重新设置一次。
